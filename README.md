# Lumen-Ledger

Aplicação web de controle financeiro pessoal para registrar receitas e despesas, acompanhar o saldo e organizar a vida financeira de forma simples.

## Funcionalidades

- Cadastro de receitas e despesas
- Categorização das movimentações
- Cálculo automático de saldo, receitas e despesas
- Exclusão de lançamentos
- Persistência dos dados no navegador com `localStorage`
- Interface responsiva para celular e desktop

## Como executar localmente

1. Clone o repositório:

```bash
git clone [https://github.com/lietluan22/Lumen-Ledger.git](https://github.com/lietluan22/Lumen-Ledger.git)
```

2. Entre na pasta:

```bash
cd Lumen-Ledger
```

3. Abra o arquivo `index.html` no navegador.
